# 💍 WelcomeToMiddleEarth

Plugin LOTRO communautaire qui accompagne la progression du personnage : compétences non apprises, gains de niveau, repères de traits et guide des objets légendaires.

**🌍 Langues / Languages / Sprachen :** 🇫🇷 Français · 🇬🇧 English · 🇩🇪 Deutsch

---

## 🇫🇷 Français

### 📖 Présentation

**WelcomeToMiddleEarth** est une maintenance communautaire du plugin original de **Thardariel / Die Bewahrer Mittelerdes**. Il utilise les données fournies par le client LOTRO pour afficher les compétences encore non apprises et accompagner les principaux paliers de progression.

### ✨ Fonctionnalités

- Liste des compétences non apprises avec nom, icône et description du client.
- Filtrage de la progression normale des classes.
- Popup de montée de niveau avec gains obtenus et prochains paliers.
- Gestion des sauts de plusieurs niveaux.
- Repères de points de trait.
- Conservation du combat monté de niveau 75 et des gambits de Sentinelle.
- Guide intégré des objets légendaires.
- Dernière montée de niveau réouvrable.
- Progression prise en charge au-delà du niveau 140.
- Interface FR / EN / DE.

### 📦 Installation

Copie le dossier **Dusk** dans :

```text
Documents\The Lord of the Rings Online\Plugins\
```

Puis en jeu :

```text
/plugins refresh
/plugins load WelcomeToMiddleEarth
```

### 🎮 Utilisation

Le plugin peut afficher automatiquement la fenêtre de progression lors d’une montée de niveau. La fenêtre principale permet aussi de consulter les compétences à venir et les différents repères de progression.

### ⌨️ Commandes

- `/wtme` — ouvrir le suivi.
- `/wtme levelup` — réafficher la dernière montée de niveau.
- `/wtme help` — ouvrir le guide légendaire.
- `/wtme diagnostic` — afficher l’état de lecture des compétences.

### ⚙️ Sauvegardes & réglages

Les préférences et la dernière montée de niveau détectée sont sauvegardées par personnage. Le plugin possède son propre espace de sauvegarde Lua.

### 🌍 Langues

L’interface est disponible en **français, anglais et allemand**. Les noms, icônes et descriptions de compétences proviennent directement du client LOTRO utilisé.

### ⚠️ Limites / notes

Le niveau seul ne garantit pas toujours l’accès à une compétence : traits, quêtes ou autres prérequis peuvent intervenir. Les informations de progression sont donc des repères, pas un remplacement du journal ou du panneau de compétences du jeu.

### 🐛 Bugs & suggestions

Utilise les [Issues GitHub](https://github.com/Dusk-92/WelcomeToMiddleEarth/issues).

### 🙏 Crédits

Plugin original : **Thardariel / Die Bewahrer Mittelerdes**.  
Maintenance communautaire : **Dusk-92**.

## 🇬🇧 English

### 📖 Overview

**WelcomeToMiddleEarth** is a community-maintained version of the original plugin by **Thardariel / Die Bewahrer Mittelerdes**. It uses data exposed by the LOTRO client to show untrained skills and useful character-progression milestones.

### ✨ Features

- Untrained skill list using names, icons and descriptions from the game client.
- Filtering for normal class progression.
- Level-up popup with newly gained and upcoming rewards.
- Multi-level jump handling.
- Class trait point reminders.
- Level-75 mounted combat and Warden gambits kept in progression.
- Built-in Legendary Items guide.
- Last detected level-up can be reopened.
- Progression support beyond level 140.
- FR / EN / DE interface.

### 📦 Installation

Copy the **Dusk** folder into:

```text
Documents\The Lord of the Rings Online\Plugins\
```

Then in game:

```text
/plugins refresh
/plugins load WelcomeToMiddleEarth
```

### 🎮 Usage

The plugin can automatically display its progression window after a level-up. The main window can also be opened manually to review upcoming skills and progression milestones.

### ⌨️ Commands

- `/wtme` — open progression tracking.
- `/wtme levelup` — reopen the last detected level-up.
- `/wtme help` — open the Legendary Items guide.
- `/wtme diagnostic` — show skill-reading status.

### ⚙️ Saved data & settings

Preferences and the last detected level-up are saved per character. The plugin uses its own Lua data apartment.

### 🌍 Languages

The interface is available in **English, French and German**. Skill names, icons and descriptions are read from the active LOTRO client.

### ⚠️ Limitations / notes

Level alone does not always guarantee access to a skill: traits, quests or other requirements may apply. The progression view is therefore a guide, not a replacement for the game's Skill panel or quest journal.

## 🇩🇪 Deutsch

### 📖 Übersicht

**WelcomeToMiddleEarth** ist eine gemeinschaftlich gepflegte Version des ursprünglichen Plugins von **Thardariel / Die Bewahrer Mittelerdes**. Es verwendet Daten des LOTRO-Clients, um ungelernte Fertigkeiten und wichtige Fortschrittsmeilensteine anzuzeigen.

### ✨ Funktionen

- Liste ungelernter Fertigkeiten mit Namen, Symbolen und Beschreibungen aus dem Spielclient.
- Filterung der normalen Klassenentwicklung.
- Stufenaufstiegsfenster mit erhaltenen und kommenden Belohnungen.
- Unterstützung für mehrere übersprungene Stufen.
- Hinweise auf Klasseneigenschaftspunkte.
- Berittener Kampf ab Stufe 75 und Gambits des Hüters bleiben berücksichtigt.
- Integrierter Leitfaden für legendäre Gegenstände.
- Letzter erkannter Stufenaufstieg kann erneut geöffnet werden.
- Fortschritt über Stufe 140 hinaus.
- Oberfläche auf FR / EN / DE.

### 📦 Installation

Den Ordner **Dusk** nach folgendem Pfad kopieren:

```text
Documents\The Lord of the Rings Online\Plugins\
```

Danach im Spiel:

```text
/plugins refresh
/plugins load WelcomeToMiddleEarth
```

### 🎮 Verwendung

Nach einem Stufenaufstieg kann das Plugin automatisch das Fortschrittsfenster anzeigen. Das Hauptfenster kann außerdem manuell geöffnet werden, um kommende Fertigkeiten und Meilensteine zu prüfen.

### ⌨️ Befehle

- `/wtme` — Fortschrittsübersicht öffnen.
- `/wtme levelup` — letzten erkannten Stufenaufstieg erneut anzeigen.
- `/wtme help` — Leitfaden für legendäre Gegenstände öffnen.
- `/wtme diagnostic` — Status der Fertigkeitsauslesung anzeigen.

### ⚙️ Gespeicherte Daten & Einstellungen

Einstellungen und der letzte erkannte Stufenaufstieg werden pro Charakter gespeichert. Das Plugin verwendet einen eigenen Lua-Datenbereich.

### 🌍 Sprachen

Die Oberfläche ist auf **Deutsch, Englisch und Französisch** verfügbar. Namen, Symbole und Beschreibungen der Fertigkeiten stammen direkt aus dem aktiven LOTRO-Client.

### ⚠️ Einschränkungen / Hinweise

Die Stufe allein garantiert nicht immer den Zugriff auf eine Fertigkeit. Eigenschaften, Aufgaben oder andere Voraussetzungen können zusätzlich nötig sein. Die Anzeige ist daher ein Leitfaden und ersetzt nicht das Fertigkeitenfenster oder das Aufgabenbuch.
